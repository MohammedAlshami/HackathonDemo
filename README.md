# UMHackathonDemo

A dashboard-style project built for the **UM Hackathon**: schedule/finance UI with responsive
views (lg / sm / xs) and supporting assets. Built with Next.js/React + Tailwind, plus a Python
backend for any chart/report helpers.

## Features

- Responsive dashboard layouts (`public/*_dashboard.svg`)
- Schedule and analytics cards
- Tailwind + DaisyUI styling
- Component-driven pages under `app/` and `components/`

## Tech stack

- **Frontend:** Next.js, React, TypeScript, Tailwind, DaisyUI, Framer/Emotion, MUI Charts
- **Backend (optional helpers):** Python (Flask), Pyrebase/Firebase
- **Data:** JSON/CSV dashboards, schedule data

## Getting started

```bash
npm install
npm run dev    # http://localhost:3000
```

Python helpers:

```bash
pip install -r requirements.txt   # where available
```
